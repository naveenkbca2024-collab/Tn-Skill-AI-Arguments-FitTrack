🚀 Getting Started

The repository is organized primarily around project documentation and development phases.

To work with the project:

1. Clone or download the repository.
2. Open the repository in your development environment.
3. Navigate to the required project phase.
4. Review the available deliverables.
5. Add or update the relevant project files.
6. Keep each deliverable inside its corresponding phase folder.
7. Update the documentation as the project progresses.
